# boltmark

Bolt and reshape mark text streams with deterministic transforms.

**Site:** https://theworker02.github.io/boltmark/

## Install / run

```bash
git clone https://github.com/theworker02/boltmark.git
cd boltmark
node src/cli.js
node --test
```
